# Configuration Review

Ensure configs are safe, clear, and hard to misconfigure.

## Check
- Secrets in config or committed files
- Environment differences that are easy to get wrong
- Unsafe default values
- Missing validation of config at startup
- Feature flag hygiene and cleanup
- Documentation of important settings
