# Frontend Review

Assess user-facing code quality and edge cases.

## Check
- Basic accessibility (labels, keyboard, contrast, semantics)
- State management clarity and predictability
- Performance (unnecessary re-renders, large bundles, layout thrash)
- Error, loading, and empty states
- Responsive behavior and overflow
- Client-side validation vs server expectations
