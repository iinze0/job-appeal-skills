# Job Appeal Skills

A small collection of production-grade agent skills designed to make you more appealing to employers.

These skills force rigorous thinking about:

- Code quality and "no-slop"
- Architecture and trade-offs
- Security
- Shipping real outcomes

If you built or contribute to tools like this, you demonstrate that you care about the things hiring managers actually care about: maintainability, judgment, and delivery.

## Skills included

| Skill | What it proves |
|-------|----------------|
| **grill** | You can give and take sharp, specific feedback |
| **architecture** | You think in systems, constraints, and trade-offs |
| **security-lens** | You consider real threats, not just happy paths |
| **ship** | You focus on outcomes and done, not perfect |

## Usage

These are designed for Grok / agent systems that support skills (SKILL.md format).

Copy a skill folder into your skills directory, or use the installer.

## Why this exists

Most portfolio projects show that you can follow a tutorial.  
These skills show that you can think like someone who ships software that other people depend on.
